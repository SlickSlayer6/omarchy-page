# Omarchy homepage redesign

A homepage redesign for [omarchy.org](https://omarchy.org), for DHH’s design-team call.

Static HTML and CSS, same shape as [`omacom/omarchy-site`](https://github.com/omacom/omarchy-site). Catppuccin is the default theme; the dots in the bar recolor the page with stock Omarchy palettes.

- `index.html` — the homepage
- `chrome.html` — how inner pages would wear the compact bar
